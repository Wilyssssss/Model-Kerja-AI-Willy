## 🚀 4. Cara Memulai Proyek Website Baru (1 Kalimat Sakti)

Buka percakapan baru di Antigravity, lalu ketik satu kalimat ini:

> **"Buat proyek website [nama_proyek] di [folder_tujuan] dan inisialisasi Willy AI Working Model."**

**Contoh nyata:**
> *"Buat proyek website sistem_kasir di D:\Data_web\sistem_kasir dan inisialisasi Willy AI Working Model."*

Dalam hitungan 3 detik, AI akan otomatis:
1. Membuat folder proyek lengkap dengan struktur standar industri.
2. Memasang buku aturan lokal (`AGENTS.md`), memori harian (`working.md`), dan papan tugas (`task.md`).
3. Mengunci keamanan folder via `.htaccess` dan memasang skrip rilis bersih `build_upload.ps1`.
4. Anda tinggal ketik `willy briefing` atau `willy run` untuk langsung mulai berkarya!

## 🔍 5. Bedah Benda-Benda di Dalam Folder Proyek

Bagi pemula yang ingin memahami apa isi folder proyeknya:

- **`AGENTS.md` (Undang-Undang Proyek)**: Buku pedoman mutlak bagi AI saat bekerja di folder tersebut.
- **`working.md` (Buku Diary Anti-Pikun)**: Tempat AI mencatat sampai baris mana dia bekerja hari ini, sehingga saat Anda membuka chat baru besok, dia langsung paham konteksnya.
- **`task.md` (Papan Tulis Antrian Tugas)**: Tempat mencatat daftar tugas (TASK-001, TASK-002) agar pekerjaan berurutan dan tidak loncat-loncat.
- **`build_upload.ps1` (Tukang Sapu & Pengepak Koper)**: Skrip pembersih otomatis sebelum web diunggah ke server cPanel hosting.
- **`MIGRATION_LOG.md` (Buku Sertifikat Database)**: Catatan resmi setiap kali ada perubahan tabel atau kolom database.
- **`.htaccess` (Pagar Satpam Keamanan)**: Mencegah hacker luar mengeksekusi file berbahaya di folder upload Anda.

## 🛠️ 6. Cara Mengembangkan & Merevisi di Masa Depan

Karena seluruh framework ini berupa **file teks Markdown biasa (`.md`)**, Anda bebas memodifikasinya kapan saja tanpa perlu kompilasi:

### A. Menambah Perintah / Jurus Baru
Buka file `C:\Users\Willy\.gemini\config\skills\willy-shortcuts\SKILL.md`, lalu tambahkan baris perintah baru Anda di tabelnya.

### B. Mengubah Sikap / Respon Asisten JARVIS
Buka file `C:\Users\Willy\.gemini\config\skills\willy-jarvis\SKILL.md`, ubah template briefing atau instruksi komunikasinya sesuai gaya Anda.

### C. Menaikkan Versi (Misal ke Versi 2.1 atau 3.0)
Cukup ubah tulisan `v2.0` menjadi `v2.1` di berkas `rules/willy-global.md` dan `README.md`. AI akan langsung otomatis menggunakan nomor versi baru tersebut di setiap responsnya.
